Raw Buffer Visualizer 2.0.2

IMPROVED
- Visual Studio 2022 17.9+ support is restored for x64 Community, Professional, and Enterprise.
- Stable Visual Studio 2026 18.x support is retained through the existing Marketplace extension identity.
- Visual Studio-native toolbar and inspector icons, responsive command labels, empty-viewer guidance, and image-aware command states improve the docked workflow.
- Supported exact OpenCvSharp/Emgu Mat lists and one-dimensional arrays are included automatically without a separate collection setting.

FIXED
- Long writable temporary-storage paths no longer block registered debugger images from reaching the docked viewer.
- The in-process package and out-of-process debugger providers now use the Visual Studio 17.9 SDK compatibility line.

INCLUDED
- Connect Doctor, checked 2D buffer validation, automatic inspection, registered Bitmap/OpenCvSharp/Emgu paths, and live-source invalidation remain included.

SCOPE
- Camera acquisition/control, lighting, PLC/I/O, 3D visualization, and proprietary SDK adapters remain outside this release.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. What's New toggles them later; Dismiss records the version as seen.

Raw Buffer Visualizer 2.0.6

PACKAGE UPDATE
- Advances the Marketplace package identity from public 2.0.5.0 to 2.0.6.0 because published versions are immutable.
- Makes no functional or compatibility change to the validated 2.0.5 behavior.

INCLUDED
- Exact debugger expression names and native Ptr versus Pixels provenance remain included.
- Complete image-array registration, fail-closed pointer reads, and negative-stride Bitmap correction remain included.
- Clear all, direct concurrent dictionaries, first-use ImagePtr handoff, Connect Doctor, automatic inspection, and registered Bitmap/OpenCvSharp/Emgu paths remain included.
- Visual Studio 2022 17.9+ and stable Visual Studio 2026 18.x remain the supported installation targets.

SCOPE
- Camera acquisition/control, lighting, PLC/I/O, 3D visualization, and proprietary SDK adapters remain outside this release.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. What's New toggles them later; Dismiss records the version as seen.

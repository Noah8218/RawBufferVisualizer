Raw Buffer Visualizer 1.0.53

NEW
- Environment Check reports the current Visual Studio host, loaded extension version, and temporary-storage writability before optional contributor/media tools.
- Refresh and diagnostic-report copy do not scan a frame, open an image, install software, or change registration.

FIXED
- Large pointer-backed previews use a bounded cold-page-read budget, keeping first access to dense 100k/200k fixtures below the existing five-second gate on the restored workstation.
- Automatic Vision Inspector and Smart Type Mapper layout checks now follow the current workspace seam and newest restored VSSDK package instead of stale implementation/package paths.

IMPROVED
- Optional .NET, Visual Studio workload, and FFmpeg actions require confirmation and open only Visual Studio Installer or official guidance. Nothing is installed silently.
- The environment report excludes credentials, environment-variable values, and image payloads, and warns that local paths must be reviewed before sharing.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. Use What's New to reopen them later.

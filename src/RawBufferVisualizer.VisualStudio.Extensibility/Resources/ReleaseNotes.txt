Raw Buffer Visualizer 2.0.7

SIGNED 32-BIT MATRICES
- Opens OpenCvSharp CV_32SC1 and Emgu CV Cv32S C1 as Int32 images.
- Includes direct debugger visualizers, Automatic Inspector, and supported Mat collections.
- Uses signed min/max grayscale autoscaling while keeping exact signed pixel values and four raw bytes in the inspector.
- Preserves explicit byte order and padded stride for pointer, snapshot, mapped int[], sampled, and tiled paths.

COMPATIBILITY
- Visual Studio 2022 17.9+ and stable Visual Studio 2026 18.x remain the supported installation targets.
- CV_32SC1 is one signed 32-bit channel. Multi-channel signed Mats and 3D data remain outside this release.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. What's New toggles them later; Dismiss records the version as seen.

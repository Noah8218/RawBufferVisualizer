Raw Buffer Visualizer 1.0.52

NEW
- Automatic Vision Inspector can inspect exact OpenCvSharp and Emgu CV Mat lists and one-dimensional arrays when the saved Mat collections option is enabled.
- Collection elements fail independently, so null or disposed Mats do not hide valid images.

FIXED
- Updated the stable Visual Studio Extensibility SDK so registered debugger visualizers activate on Visual Studio 2026 18.x.
- Open file-backed snapshots now hold a lease so the 24-hour stale sweep cannot remove data that is still displayed.
- Preview-to-full handoff replacement releases the prior payload, and closing/removing a document releases its current payload.

IMPROVED
- Claimed handoff ACK/NACK coordination and document activation/removal/disposal now have independent tested owners.
- New and selected images keep an aspect-correct Fit; manual zoom and pan remain stable.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. Use What's New to reopen them later.

Raw Buffer Visualizer 2.0.9

NATIVE IMAGE TRANSFER
- Pointer-backed OpenCvSharp Mat, Emgu CV Mat, ImagePtr, and RawBufferView payloads at or above 8 MiB use checked live process-memory reads instead of repeated full-image debugger RPC snapshot requests.
- Pointer-backed images below 8 MiB and non-pointer sources retain 4 MiB snapshot chunks.
- Live rows become UNAVAILABLE after Continue or process exit; copied snapshots remain viewable.

ROI MEMORY RANGE
- Inferred image length ends at the final pixel row instead of including nonexistent trailing stride padding.
- The same rule applies to registered Mats, inferred ImagePtr and RawBufferView values, and Automatic Inspector's known-image capture.
- Explicit buffer lengths remain authoritative; unreadable, released, partial, and overflowed ranges fail closed.

TECHNICAL DIAGNOSTICS
- Debugger RPC failures report the operation, source or chunk, byte offset and sizes when applicable, exception type, and HRESULT.
- The visible error uses stable technical wording while the original localized debugger exception remains in the local support report.

TOOL WINDOW RELIABILITY
- Reopening the same expression after the same failure refreshes its existing error row with a new report ID instead of appending duplicate rows.
- Opening Bitmap, Mat, RawBufferView, or other registered visualizers no longer closes or replaces the pinned docked Tool Window.

COMPATIBILITY
- Visual Studio 2022 17.9+ and stable Visual Studio 2026 18.x remain the supported installation targets.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. What's New toggles them later; Dismiss records the version as seen.

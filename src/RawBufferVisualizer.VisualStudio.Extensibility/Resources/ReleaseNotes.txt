Raw Buffer Visualizer 2.0.1

FIXED
- Raised the extension package version so Visual Studio recognizes this package as an update to the existing 2.0 Marketplace entry.
- Kept the existing Marketplace extension identity and the complete 2.0 feature set unchanged.

NEW
- Connect Doctor ranks bounded interpretations inside Connect Your Buffer. Selecting one updates only the draft and preview; Save Mapping remains the persistence boundary.
- One vendor-neutral 2D contract covers RawBufferView, snapshots, mapped pointers, and mapped byte[], ushort[], and float[] buffers.
- Neutral fixtures verify descriptor metadata, transferred bytes, byte order, valid bits, and pointer ownership without a proprietary SDK.

FIXED
- Invalid dimensions, stride, buffer length, and incompatible valid bits now fail before metadata transfer.
- Mono10PackedLsb and Mono12PackedLsb reject values that contradict their fixed 10-bit and 12-bit layouts.

IMPROVED
- Current width/height/stride format alternatives remain visible instead of being crowded out by unrelated factorizations.
- Registered and mapped sources now share the same metadata-validation boundary.
- Valid Mono16 values from 1 through 16 remain accepted; executable fixtures preserve 10, 12, 14, and 16.
- Existing explicit Preview, mapping persistence, panel toggles, and no-side-effect behavior remain unchanged.

SCOPE
- Camera acquisition/control, lighting, PLC/I/O, 3D visualization, and proprietary SDK adapters remain outside this release.

The Raw Buffer Visualizer Tool Window shows these highlights once per version. What's New toggles them later; Dismiss records the version as seen.
